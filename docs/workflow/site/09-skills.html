09 Skills 索引

依交付階段列出 skill，並標出它從哪一級開始用。等級欄：L1 是基本流程就會用到；L2、L3 是導入到該級才需要；「輔助」是隨時可用、但不是流程的必經入口。

使用者輸入的 skill（/名稱）有些設了 disable-model-invocation，只能由人輸入，agent 不會自己觸發；表中以「人輸入」標示。

設定（每個 repo 一次）

skill做什麼等級來源
/setup-workflow導入入口：偵測等級（L0–L3）與擴充，建議往上一級；經人確認後寫 tracker、label、domain docs 與 adapter，並把 script 正本複製到 scripts/、記錄在 docs/agents/workflow-templates.json；/setup-workflow health 體檢已導入的專案（等級標示錯誤、分歧、隱性跨 repo 依賴），只回報不寫檔L1（人輸入）ron-skills
/setup-matt-pocock-skills產生 docs/agents/ 的 tracker、triage label、domain docs 設定L1（人輸入；/setup-workflow 會照它的步驟做，手動時才單獨用）Matt
wizard產生互動式 bash 精靈，帶人走完只有人能做的設定（建專案、token、CI secret）輔助Matt
writing-for-agents寫 skill、CLAUDE.md、adapter 這類給 agent 讀的文件輔助Matt

實作與驗證

skill做什麼等級來源
/issue-run把 ready 的 Issue 不中斷地跑到本機 candidate commit；--worker 模式由 coordinator 派出；--pool 在同一個 session 依池子順序逐張認領、逐張跑，可由 /loop /issue-run --pool 驅動L1ron-skills

tdd紅、綠、重構；第一個產品改動前先有會紅的測試L1Matt
code-reviewStandards 與 Spec 兩軸平行審查，並排回報L1Matt
diagnosing-bugs難解的 bug 與效能退化的診斷迴圈輔助Matt
codebase-design設計深模組、找 seam 的共用詞彙輔助Matt
