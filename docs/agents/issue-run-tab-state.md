# issue-run 分頁狀態：ron-skills

[issue-run.md](issue-run.md) 的必讀核心（14000 bytes，`scripts/adapter-size-budget.json`）放不下、只在自己切換分頁狀態或 hook 要求改名時才用到的段落（#470）。下一段是總則，要讀就整段讀；其後的條目用 `node scripts/adapter-line.mjs '<條目名>'` 只取需要的一條。

[分頁狀態](../../GLOSSARY.md#分頁狀態)與整個標題的格式、何時改名、` ⏸`、worktree 顯示名稱照 [ADAPTER.md](../../skills/engineering/issue-run/ADAPTER.md) 的 Tab state 段預設值，本 repo 標題用繁體中文（[CLAUDE.md](../../CLAUDE.md) 的 Language），段裡的 `orca` 寫成 `"$ORCA_CLI_COMMAND"`；這裡寫本 repo 什麼時候轉換。只換狀態用 `node scripts/tab-state.mjs <狀態>`：換成處理中時只換目前分頁標題的狀態前綴，其他文字（含階段與動作）不動；換成其他狀態時只留 `<狀態>｜<主題>`，拿掉主題後的 `｜` 段（階段、動作）與 ` ⏸`（#334）；要留別的段（例如 `｜已合入 PR #130`）時帶 `--topic` 重設整個標題。hook 自動切換仍只換前綴，階段與動作會留著。兩種寫法在沒有 `ORCA_TERMINAL_HANDLE` 時 exit 0 不輸出；Orca 失敗時也 exit 0，stderr 印 `TAB_STATE_FAILED <狀態> <原因>`（逾時的話改名可能已送達，#295）；session 在 split 出來的 pane（不是分頁的第一個 pane，例如 `orca-session-split.mjs` 不帶 `--tab`、`--worktree` 開的）時 exit 0、只印 `TAB_STATE_SKIP split`，分頁標題歸分頁擁有者，不必重跑或改用 `--topic`（#378；`claude-hook-tab-state.mjs` 的自動切換還沒有這個判斷）。session 開頭改用 `node scripts/tab-state.mjs 處理中 --topic "<主題>"` 一次設定前綴與主題（`<主題>` 是標題格式裡狀態前綴之後的部分）：本機記錄的可能還是同一個 handle 上一個 session 的標題，只換前綴會帶出舊主題（#141）。`.claude/settings.json` 掛的 `scripts/claude-hook-tab-state.mjs` 自動做能用程式偵測的轉換，`Stop` 時標題沒有前綴就自己設成 `處理中`；只有改名失敗、讀回仍無前綴、標題以狀態名開頭但分隔符錯，或記錄的是其他狀態時才 exit 2 要求改名。

- **待 Retro.** 單獨跑的 `/issue-run` 在 `land.mjs` 印 `LANDED` 之後（hook 自動切；coordinator 以 `--keep-branch` 落地整合分支時它還在運作，不切）；pilot worker 寫出 `DONE <n> <sha>` 結果行時（hook 在 `Stop` 自動切，早於 coordinator 合入：worker 的交付到此為止；只認以 `/issue-run <n> --worker` 開工的 session 自己那張單的 `DONE`，coordinator 回報裡轉述的不切，`issue-pool.mjs claim` 對已落地的單印的 `LANDED` 也不切，#650）；coordinator 在 `pilot-handoff.mjs` 印 `HANDED_OFF`、交接退役之後（hook 自動切）；其他類別在使用者確認主題結束之後，自己跑 `tab-state 待 Retro`；只回答問題（工作區乾淨、沒有 commit）的 session 改跑 `tab-state 待關閉`，不必為問答跑 /retro（#399）。只開 PR 不算。
- **待關閉.** `/retro` 採用的項目已合入或開成 Issue，或候選已交給收集流程之後，由 `/retro` 最後一步在該分頁自己跑 `tab-state 待關閉`（`overlays/retro.patch`）。每個分頁都先經過待 Retro（只回答問題的 session 例外，見上一條）；待關閉的分頁由 `/retro-collect` 收集後關，其餘由使用者手動關。
- **擴充.** hook 的觸發條件要新增、覆寫或停用時，在本檔旁放 `docs/agents/tab-state.json`（格式見 `scripts/claude-hook-tab-state.mjs` 檔頭）；本 repo 目前沒有這個檔，用預設值。
- **讀不回標題.** Orca 讀不回 `terminal rename` 設的分頁標題，`tab-state` 以 handle 在本機記錄最後設定的標題（hook 也從 Bash 的 `orca terminal rename` 指令擷取）；不經 Bash 的改名（例如在 Orca 介面手動改）不會被記到，下次 `tab-state` 會以記錄的標題為準。
- **bot 聊天.** Orca bot（`~/.orca/bots/<bot>`）的 Home 聊天與排程、orchestration 開的聊天不載入本 repo 的 hook，改由使用者層 `~/.claude/settings.json` 的 `UserPromptSubmit`、`Stop` 掛 `scripts/claude-hook-bot-chat-state.mjs`（指向主 checkout，指令先以 shell 判斷 `ORCA_BOT_TOOLS_TOKEN`，一般 session 不啟動 node）。收到訊息開工換處理中；一輪結束時 Home 聊天維持處理中（它不會被關，一輪結束就是在等下一則訊息），其他聊天換待關閉（bot 聊天不跑 /retro）。只換前綴，Orca 取的原標題（`Home`、`每晚 20:30 … run 1`）不動；改名在 detached 子行程做，hook 不輸出、不等 Orca（事項 #89）。
